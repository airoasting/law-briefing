# So What 판 초안 (경영진용)

독자: 상장회사 CEO, CFO, 이사회 의장, 지배주주 측 경영진. 법을 몰라도 5분 안에 "우리 회사에 무엇이 달라지고, 나는 무엇을 결정해야 하나"를 안다.
원칙: 모든 항목을 `바뀐 것 → So what(그래서 우리에게 무슨 의미) → Now what(이번 분기에 결정할 것)` 순서로 쓴다. 법 조문은 근거로만 붙이고 본문에 쓰지 않는다. 사실과 날짜는 법률판(legal.html)과 verification.md를 따른다.

## 첫 화면

**한 문장.** 이사회가 "대주주가 고른 이사들의 회의"에서 "모든 주주에게 설명해야 하는 회의"로 바뀐다.

**그래서.** 결정 자체보다 결정의 근거를 남기는 회사가 안전하다. 2027년 3월 정기주총이 첫 시험대다.

**숫자 세 개.**
- 3분의 1: 이사회에서 독립이사가 차지해야 하는 최소 비율. 기한 2027-07-22.
- 1년: 사들인 자기주식을 소각해야 하는 기한. 계속 보유하려면 이사 전원 서명 + 매년 주총 승인.
- 2조원: 이 자산 규모를 넘는 회사는 집중투표를 막을 수 없고, 감사위원 2명을 대주주 영향 없이 따로 뽑는다.

## 다섯 가지 So What

### 1. 이사회 자리: 독립이사를 더 뽑아야 하고, 모두가 같은 시기에 찾는다
- 바뀐 것: 독립이사 비율 4분의 1 → 3분의 1. 2027-07-22까지.
- So what: 모든 상장회사가 같은 기한, 사실상 같은 주총 시즌(2027년 3월)에 후보를 찾는다. 재직 6년 상한에 걸리는 기존 이사도 교체해야 한다. 후보를 늦게 찾을수록 선택지가 줄어든다.
- Now what: 12월 안에 부족 인원과 교체 대상(6년·9년 상한)을 확정하고, 2월 초 주총 소집 이사회 전에 후보를 확정한다.

### 2. 결정 방식: "일반주주에게도 공평한가"를 설명할 수 있어야 한다
- 바뀐 것: 이사의 충실의무 대상이 회사에서 회사와 주주로 넓어졌다. 전체 주주를 공평하게 대우할 의무가 생겼다. 2025-07-22부터 이미 시행 중.
- So what: 합병, 유상증자, 전환사채, 계열사 거래, 자기주식 처분처럼 지배주주와 일반주주의 이해가 갈리는 결정이 다툼의 표적이 된다. 지금까지 법원은 경영상 목적이 분명하면 가처분을 기각했다(고려아연, 2025-12). 즉 결정이 막히는 것보다 근거가 부실한 결정이 문제가 된다.
- Now what: 이해상충 안건에는 "일반주주 영향" 검토와 경영상 목적을 이사회 자료와 의사록에 남기는 양식을 다음 이사회부터 쓴다.

### 3. 통제력: 반대 목소리가 이사회 안으로 들어올 길이 열렸다 (자산 2조원 이상)
- 바뀐 것: 집중투표를 정관으로 막을 수 없다. 감사위원 2명은 다른 이사와 따로 뽑고, 이때 최대주주는 특수관계인 지분을 합쳐 3%까지만 투표한다.
- So what: 소수주주나 행동주의 펀드가 미는 후보가 이사회와 감사위원회에 들어올 수 있는 구조가 됐다. 2026년 주총 시즌에 정관변경 주주제안은 42건에서 66건으로 늘었다(율촌 집계). 주주 소통이 IR 부서 일이 아니라 이사회 의제가 된다.
- Now what: 주요 주주 구성과 3% 합산 후 의결권을 계산해 보고, 집중투표 청구 마감(직전 연도 주총일 기준 6주 전)에 맞춘 대응 절차를 정한다.

### 4. 자본 배분: 자기주식은 "쌓아 두는 카드"가 아니라 "소각할 돈"이 된다
- 바뀐 것: 취득한 자기주식은 1년 안에 소각이 원칙이다. 예외적으로 보유하려면 이사 전원이 서명한 계획을 매년 주총에서 승인받는다. 기존 보유분도 2027년 9월 초까지 소각 대상이다(정확한 날짜는 법무 확인).
- So what: 자기주식 매입이 사실상 소각, 즉 주주환원 결정이 된다. 경영권 방어나 우호세력 매각용으로 쌓아 두기 어려워졌고, 그렇게 쓰면 의결권 자문사가 이사 선임 반대를 권고할 수 있다(Glass Lewis 정책).
- Now what: 보유 자기주식을 소각할지, 보유 목적을 주총에서 설명할지 2027년 정기주총 전에 정한다. 서명은 이사 개인 기록으로 남는다.

### 5. 외부 평가: 투자자가 같은 잣대로 비교하기 시작한다
- 바뀐 것: 국민연금은 용어를 독립이사로 바꿨고 의결권 행사 방향을 미리 공개하는 대상을 지분 5% 이상 기업으로 넓혔다. ISS는 자산 2조원 미만 회사의 이사회 독립성 기준을 3분의 1로 올리는 안을 냈다(확정 전). 2027년 제출 기업지배구조보고서부터 전자주총, 분리선출, 자기주식 현황 등을 써야 한다.
- So what: 법을 지켰는지보다 "다른 회사보다 나은가"로 평가받는다. 2026년 보고서 핵심지표 평균 준수율은 48.0%였다. 평균만 해도 절반은 못 지키고 있다는 뜻이다.
- Now what: 2027년 지배구조보고서 항목을 기준으로 우리 회사 현황표를 미리 만든다.

## 역할별 So What (렌즈)

- CEO: 이사회가 내 결정을 더 많이 묻는다. 근거 자료와 기록을 준비하는 비용이 늘지만, 그 기록이 나를 보호한다.
- CFO: 자기주식, 증자, 전환사채가 이사회와 주총의 핵심 쟁점이 된다. 자본 배분 계획을 주주에게 설명할 문장으로 준비한다.
- 지배주주·경영기획: 이사 선임과 감사위원 선임에서 지분만으로 결과를 정하기 어려워진다(2조원 이상). 이사 수 축소나 임기 조정으로 집중투표를 피하는 방식은 충실의무 다툼이 될 수 있다.
- 독립이사·이사회 의장: 감시의무는 사내이사와 같다. 내부통제가 없는데 요구하지 않았거나, 이상 신호를 외면하면 책임이 인정된다(대법원 2021다279347). 질문하고 기록을 남기는 것이 방어다.

## 하지 말아야 할 것
- 주총 직전에 독립이사 후보를 급히 찾는 것
- 의사록을 결론만 적는 방식으로 두는 것
- 자기주식을 우호세력에 넘기는 것
- 집중투표를 피하려고 근거 없이 이사 수나 임기를 바꾸는 것
