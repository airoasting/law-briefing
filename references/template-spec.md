# 브리핑 6블록 구조

매 호 같은 순서로 쓴다. 블록 순서를 바꾸지 않는 것이 이 템플릿의 핵심이다. 독자가 두 번째 호부터 어디를 보면 되는지 안다.

001호 비평(BLUE, GOLD)을 반영해 순서를 바꿨다. 결론과 '우리 회사 해당 여부'가 먼저, 조문 대비는 맨 뒤에 접어 둔다.

| # | 블록 | 질문 | 분량 |
|---|---|---|---|
| 1 | 결론 세 줄 + 가장 가까운 기한 D-day | 무엇이 바뀌었고 언제까지인가 | 3문장 |
| 2 | 우리 회사 해당 여부 | 회사 규모·유형별로 무엇이 적용되나. 적용 제외, 계산기, 용어 풀이 | 표 1개 |
| 3 | 시행 타임라인 | 공포, 시행, 유예 만료 | 부칙 근거 포함 |
| 4 | 오늘 요구할 세 가지 | 독립이사가 이사회에서 바로 요구할 자료 | 3개 |
| 5 | 이사회 질문 | 실제로 나올 질문과 답변 초안 | 5~6문항 |
| 6 | 액션 체크리스트 | 누가, 언제까지 (적용 대상 표시) | 담당, 시한 |
| 7 | 신·구조문 대비 | 정확히 어떤 문장이 바뀌었나 | 조문당 접이식 카드 |

하단 고정: 근거 검증표(조문·판례별 PASS/FAIL), 출처 목록, 기준일, 법률 자문 아님 고지, 비평 기록 요약.

## 역할별 채점 축 (10점)

- **RED 상사법 교수**. 조문 해석이 정확한가, 결론이 근거보다 앞서 나가지 않는가.
- **SILVER 기업법무 변호사(지배구조 자문)**. 주총·이사회 실무에서 그대로 써도 되는가, 빠진 실무 리스크는 없는가.
- **BLUE 커뮤니케이션 비평가**. 법을 모르는 CEO가 3분 안에 이해하는가, 불안을 키우지 않으면서 긴장은 유지하는가.
- **GOLD 상장사 사외이사**. 이사회 30분 전에 이것만 읽고 들어가도 질문에 답할 수 있는가.

# 경영진판(So What) 구조

법률판(`legal.html`)이 끝난 뒤 만든다. 경영진판은 법률판의 사실만 쓰고 새 사실을 더하지 않는다. 문체는 '~입니다/~습니다'.

| # | 블록 | 내용 |
|---|---|---|
| 1 | 한 문장 + So what | 이 개정이 경영진의 일을 어떻게 바꾸는지 한 문장. 특정 집단(대주주 등)을 비난하는 표현 금지 |
| 2 | 회사 규모 스위치 | 해당하는 것 / 다가오는 날짜를 규모별로 바꿔 보여 줌 |
| 3 | So What 다섯 장 | 각 장은 `바뀐 것 → 그래서 → 할 일`. 제목 15자 안팎. 근거는 작은 글씨 |
| 4 | 역할별 렌즈 | CEO, CFO, 지배주주 측, 독립이사. 역할마다 한 문장 + 구체 행동 3~4개 |
| 5 | 하지 말아야 할 것 + 주총 전 결정 | 결정마다 시한 |
| 6 | 만든 방식 | 페르소나별 라운드 점수 |

## 경영진판 페르소나 (6인)

- GOLD-CEO (2조원 미만 회사): 5분 안에 "내가 뭘 결정하지"가 보이는가
- GOLD-CFO (2조원 이상 그룹 계열): 자본 배분, 자기주식, 의결권 계산, 날짜
- GOLD-지배주주 측 경영기획실장: 위협 과장 또는 회피 요령으로 읽히지 않는가
- GOLD-이사회 의장(독립이사): 이사회에서 이 페이지로 안건을 정할 수 있는가
- RED 상사법 교수(법률 가드): 쉽게 쓰다가 법적 의미가 바뀌지 않았는가
- BLUE 경영 커뮤니케이션: So what이 사실 재진술에 그치지 않는가

001호에서 쉽게 쓰는 과정에서 생긴 오류 유형: 하급심 1건을 일반 원칙으로 씀, 예외 요건 생략(자기주식 보유는 법정 사유가 있을 때만), 적용 대상 혼동(2조원 이상/미만), 인과 비약(주주제안 증가를 이사회 진입 근거로 씀).
