# 발행 전 체크리스트

매 호 발행 전에 전 항목을 확인한다. 하나라도 빠지면 발행하지 않는다.

## 근거
- [ ] 모든 조문 인용이 `verify_document`로 PASS 또는 경고 공개 상태다
- [ ] 모든 판례 인용이 `check_precedent`로 생존 확인되었다
- [ ] 공포일, 시행일, 유예기간(부칙)을 법제처 DB 또는 관보로 확인했다
- [ ] 숫자와 통계에는 출처와 기준 시점이 붙어 있다
- [ ] 출처가 어긋나는 사실은 어긋난다고 적었다

## 판단
- [ ] "책임이 늘었다/줄었다" 같은 결론마다 조문 근거가 한 줄 이상 붙어 있다
- [ ] 아직 판례가 쌓이지 않은 해석은 "해석이 갈린다"로 표시했다
- [ ] 회사 규모(상장, 자산 2조원 이상 등)별 적용 차이를 구분했다

## 독자
- [ ] 첫 화면에서 "무엇이, 언제부터, 누구에게"가 보인다
- [ ] 이사회 질문 5개와 답변 초안이 있다
- [ ] 액션마다 담당 조직과 시한이 있다
- [ ] 법률 용어는 첫 등장 시 한 줄로 풀었다

## 형식
- [ ] "법률 자문이 아니다" 고지가 있다
- [ ] 고지문은 정본 한 가지만 쓴다. 상단은 짧은 요약, 하단은 전체 고지. 정본 문구는 001호 `docs/index.html` 하단을 따른다
- [ ] 고지문에 기준 시점 이후 변화 미반영, 정확성·완전성 비보증 문구가 있다. "책임을 지지 않는다" 같은 전면 면책은 쓰지 않는다
- [ ] 회사에 지시하는 문장("~하셔야 합니다", "~하시길 권합니다")이 없다. 법이 요구하는 것은 사실로, 회사가 할 일은 "점검 항목", "검토 대상"으로 쓴다
- [ ] 유료 판매, 특정 회사 맞춤 판단으로 연결하지 않는다 (변호사법 제109조 위험)
- [ ] 외부 공개 전 변호사 1인 검토를 받았거나, 받지 않았다면 그 사실을 알고 발행한다
- [ ] 기준일(as of)이 표기되어 있다
- [ ] 줄표(em dash)를 쓰지 않았다
- [ ] 과장어(혁신적, 획기적, 게임 체인저)를 쓰지 않았다
