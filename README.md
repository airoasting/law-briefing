# Board Law Briefing

법령이 바뀔 때마다 상장회사 이사회가 이사회 30분 전에 읽을 수 있는 브리핑 한 장을 만드는 작업 틀이다.

- 분류: **Prototype** (PROJECTS.md 기준). 같은 틀로 세 호를 찍어 반복할 수 있는지 확인되면 Core Asset으로 올린다.
- 연결 축: AI Work OS(5-Color Harness 적용 사례), Executive Intelligence(경영 리더용 법률 정보)
- 첫 호: `issues/001_상법_독립이사/briefing.html`

## 왜

리더가 묻는 것은 "조문이 어떻게 바뀌었나"가 아니라 "다음 이사회에서 무엇을 결정하나"다. 법률 콘텐츠에서 가장 큰 위험은 조문과 판례를 지어내는 것이다. 그래서 이 틀은 두 가지를 강제한다.

1. 모든 인용은 korean-law(법제처 Open API)로 검증하고, FAIL이 나오면 발행하지 않는다.
2. 한 사람이 쓰고 끝내지 않는다. 역할을 나눠 채점하고 다시 쓴다.

## 001호에서 배운 것 (다음 호에 반영)

- 법제처 점검 시간에는 DB를 기억으로 대신하지 않는다. 점검 공지 시각을 확인하고 기다렸다.
- `read_law`는 부칙을 읽지 못한다. 부칙은 law.go.kr 본문 페이지(`lsInfoR.do?lsiSeq=<MST>`)에서 대조했다.
- 같은 조문 번호가 시점에 따라 다른 내용일 수 있다. 001호의 제542조의14가 그런 경우다(현행은 자기주식 신탁, 2027년부터 전자주총).
- 1차 비평에서 가장 큰 감점은 법률 오류가 아니라 독자 분리였다(GOLD 6.0). 첫 화면에 '우리 회사 해당 여부'를 둔다.
- 외부 리서치 에이전트가 요청문의 예시 판례 오류(2021다279347의 사건명)를 잡아냈다. 리서치 요청문의 예시는 검증 대상으로 취급한다.

## 갱신 기준

- 시행 예정 개정이 시행되면(001호는 2027-01-01) 해당 호의 기준일과 경고 표기를 갱신한다.
- 판례가 새로 나오면 `check_precedent`로 생존을 다시 확인한다.
